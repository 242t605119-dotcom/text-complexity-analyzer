# Text Complexity Analyzer

A simple Python application that analyzes text and generates a complexity report.

## Features

- Counts characters
- Counts words
- Counts sentences
- Finds the longest word
- Calculates average word length
- Finds the most frequently used word
- Calculates a text complexity score
- Classifies text as Simple, Moderate, Complex, or Very Complex

## Technologies Used

- Python
- Regular Expressions
- Collections Counter
